summary: "Software can be run almost anywhere and at any time, yet this flexibility is under-exploited for cutting carbon emissions. \textbf{GreenestRoute} is an open-source scheduler that routes flexible compute jobs to a server location and start time that jointly minimise CO\textsubscript{2} emissions and server cost, making green scheduling a practical default. It integrates with the Carbon Aware SDK~\cite{carbonawaresdk} for near-real-time and forecast grid intensity data, and converts projected emissions into a monetary carbon cost using the Social Cost of Carbon (SCC) by default. Organisations can also override this with configurable market carbon prices (e.g., from the EU ETS sourced via ICAP~\cite{icap}) to weigh their options based on internal budgets. This report describes the system design, methodology, and evaluation on historical GitHub Actions workloads."
